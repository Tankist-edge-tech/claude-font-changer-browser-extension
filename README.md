# Claude font changer browser extension

Browser extension allowing you to change fonts on Claude web interface

## Install steps:

1. Download zip in this repository, unzip it in location you want the extension to live
2. In your web browser Chrome in this case, go to `chrome://extensions/` and enable developer mode
3. Click import extension and navigate to folder where your unzipped extension lives
4. Done


 Extension was written by Claude itself
